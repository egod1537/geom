# checker

`checker` is the geom monorepo C++ library for GUI-first stress and regression
testing. Testlib generators run as subprocesses; parsing, validation, reference
computation, target calls, normalization, comparison, and visualization run
in-process as typed C++ callbacks.

The public design notes may still say `geom_checker`; the implementation in
this repo is named `checker`.

## Build

Requires C++17, POSIX, GLFW3, and OpenGL.

```bash
cmake -S checker -B checker/build
cmake --build checker/build
```

The checker subdirectory is also standalone-buildable:

```bash
cd checker
cmake -S . -B build
cmake --build build
```

## CLI

Default execution opens an ImGui window. Use `--headless` for CI, scripts, or
Codex runs.

```bash
./my_stress                  # GUI, Invocations tab
./my_stress stress           # GUI, Invocations tab and auto-run
./my_stress stress small     # GUI, named stress entry
./my_stress build            # GUI, Tests tab after rebuilding scripted cases
./my_stress cases            # GUI, Tests tab

./my_stress --headless stress
./my_stress --headless stress small
./my_stress --headless build
./my_stress --headless cases
```

The 2D plot callback is optional. If `gui.render_plot_2d` is not set, the Case
Detail modal shows only the Text tab.

## Consumer Layout

```text
tests/
├── gen/
│   └── gen_basic.cpp
├── stress_test.cpp
├── gen.script
└── cases/
    ├── 001_basic.txt
    ├── failed/.gitkeep
    └── README.md
```

`gen.script` combines fixed case generation and stress recipes:

```text
case basic  gen_basic --n 5 --max 10 1
stress small 1000 gen_basic --n [3..10] --max [1..20] [1..1000000]
```

`case` entries are generated by `build` into `cases/<name>.txt`. `stress`
entries are sampled by `stress` or `stress <name>`.

Files in `cases/` may be either legacy input-only tests or manual
input/expected-output tests:

```text
[input]
raw input bytes
[output]
expected output bytes
```

Input-only tests compare the target against `reference(input)`. Tests with an
`[output]` section compare the target against `parse_output(output)`, so
`cfg.parse_output` must be set when this format is used.

## C++ API

```cpp
#include <checker/dispatch.h>
#include <checker/gui.h>
#include "gen_paths.h"

int main(int argc, char** argv) {
    checker::StressConfig<Input, Output> cfg;
    cfg.script_path = checker::generated::script_path;
    cfg.cases_dir = checker::generated::cases_dir;
    cfg.failed_dir = std::filesystem::path(checker::generated::cases_dir) / "failed";
    cfg.gen_resolver = checker::generated::gen_path;
    cfg.gen_source_resolver = checker::generated::gen_source_path; // optional, enables Files tab source view
    cfg.parse = parse_input;
    cfg.parse_output = parse_output; // optional, enables cases with [output]
    cfg.reference = brute_reference;
    cfg.target = call_algorithm;
    cfg.normalize = normalize_output;
    cfg.gui.format_output = format_output;
    cfg.gui.render_plot_2d = render_plot_2d; // optional
    cfg.gui.window_title = "my algorithm checker";
    return checker::run(cfg, argc, argv);
}
```

Failures archive raw generated bytes under `cases/failed/auto_<entry>_<i>.txt`.

## Case Detail

Case Detail always shows raw input plus a Text tab. The Text tab uses
`gui.format_output(output)` when provided. If `gui.render_plot_2d` is provided,
the modal also shows a Plot tab. You can use raw ImGui calls or the helper
canvas:

```cpp
void render_plot_2d(const Input& in, const Output& ref, const Output& out, bool matched) {
    checker::gui::Canvas2D canvas;
    canvas.fit_bbox(-10, -10, 10, 10);
    canvas.grid(IM_COL32(60, 60, 60, 255));
    // draw input, reference, and target
}
```

## CMake Helper

Consumer tests use one helper call:

```cmake
checker_add_stress_test(my_stress
    GENERATORS gen_basic gen_edge
    SOURCES    src/stress_test.cpp
    GENERATOR_DIR src
    SCRIPT     tests/gen.script
    CASES_DIR  tests/cases
    LINK       my_algorithm::my_algorithm)
```

The helper builds generator executables, links them to `checker::testlib`,
generates `gen_paths.h`, and links the stress executable to `checker::checker`.

## Example

```bash
cmake --build build --target sort_uniq_stress
build/examples/sort_uniq/sort_uniq_stress              # GUI
build/examples/sort_uniq/sort_uniq_stress --headless build
build/examples/sort_uniq/sort_uniq_stress --headless cases
build/examples/sort_uniq/sort_uniq_stress --headless stress small
```

## Install

```bash
cmake --install build --prefix ~/local/checker
```

```cmake
find_package(checker REQUIRED)
target_link_libraries(my_target PRIVATE checker::checker)
```

`checker::testlib` exposes vendored `testlib.h` for generator binaries.
