# sort_uniq Cases

## Input

```text
N
a_1 a_2 ... a_N
```

`N >= 0`; values are signed 32-bit integers.

## Output

The typed output is `std::vector<int>` containing all distinct input values in
ascending order. The example does not serialize output files; `stress_test.cpp`
compares typed vectors in-process.

## Cases

- `001_trivial.txt`: frozen hand-written case, answer `[1, 2, 3]`
- `all_same.txt`: generated by `gen.script`, answer depends on generated raw input
- `mixed.txt`: generated by `gen.script`, answer depends on generated raw input
